# 1. Tolofoly (Inspired by Real Estate Trading Board Games)

> A modern and interactive recreation of the classic board game, designed to be played with a central screen (TV) and mobile devices as controllers.

![Project Status](https://img.shields.io/badge/Status-In_Development-yellow)
![License](https://img.shields.io/badge/License-MIT-blue)

## Overview

**Tolofoly** proposes a hybrid experience:
1.  **The Board:** A web application running on a TV or large monitor, displaying the game state, properties, and animations.
2.  **The Controllers:** Players enter the room via their mobile phones through QR Code and perform actions (roll dice, buy, negotiate) in the palm of their hands.

The goal is to eliminate the complexity of counting money and organizing cards while maintaining the social interaction of a board game.

## Key Features

* **Multiplayer in Real-Time:** Instant synchronization via WebSockets (**Socket.io**).
* **Host/Client Architecture:** Clear separation between board visualization and player interface.
* **Fortune and Misfortune Cards Pre-generated by AI:** Dynamic events that alter game flow (e.g., economic crises, personalized luck/setbacks), with a touch of personality using the players' own names.
* **Smooth Animations:** Rich interface using **Framer Motion**.
* **National Theme:** Properties based on major national landmarks.

## How to Run Tolofoly Locally

Since the project is hybrid, you'll need to run the "brain" (Server) and "body" (Client) in separate terminals.

### Prerequisites
* **Node.js** (v18+ recommended)
* **npm** or **yarn**
* A mobile phone connected to the same Wi-Fi network as the computer (to test the controller) or a browser.

## Step 1: The Server (API + Socket)
The server manages game state and synchronization.

### Clone the repository
```
git clone https://github.com/Tolofi/Tolofoly-plus-refatored.git
```

### Enter the server folder
```
cd tolofoly-plus-refatored/server
```

### Install dependencies and run
```
npm install
npm run start
```  
The terminal should confirm: "Server running on port 3000"

## Step 2: The Client (TV + Mobile)
The visual interface that renders the board and controls.

### Open a NEW terminal and enter the client folder
```
cd Cliente/my-app
```

### Install dependencies and run
```
npm install
npm run dev
```
Access the local link (e.g.: http://localhost:5173)

## Step 3: Playing
Open the front-end link on your PC (it will be the TV/Board).

1.  **Setting up the Host:** On the initial screen, click **"Enter IP"**.
    * *If you're the first:* Enter your machine's local IP and the port (3000).
    * *To invite:* Click the **"Share IP"** button. This will generate the QR Code.
2.  **Connecting Players:**
    * On your mobile, click **"Enter IP"** and then **"Scan QR Code"**.
    * Accept the camera permission and read the code.
    * If everything is correct (same Wi-Fi network), you'll be connected.
3.  **Starting:**
    * Enter your name and click **"Play"**.
    * On the waiting screen, click **"Ready"**.
    * When everyone is ready, the game starts.

> **Connection Tip:** If the QR Code doesn't connect, make sure your Windows/Linux Firewall isn't blocking the Node.js port.
